How It Works

셀럽 히어, 이렇게 작동해요

팬들이 목격한 셀럽의 위치를 실시간으로 지도에 공유합니다. 지금 어디에 있는지 바로 확인하세요.

01
📍
목격 등록
셀럽을 목격하면 앱에서 위치와 함께 실시간으로 등록합니다.
02
🗺️
지도 확인
실시간으로 업데이트되는 지도에서 내 주변 셀럽 위치를 확인합니다.
03
🔔
알림 수신
좋아하는 셀럽이 내 근처에 나타나면 즉시 푸시 알림을 받습니다.
04
🤝
팬과 소통
같은 장소의 팬들과 정보를 공유하고 함께 특별한 순간을 만듭니다.
For Creators

유튜버를 위한
콘텐츠 시나리오

셀럽 히어로 새로운 콘텐츠 포맷을 만들어 보세요. 팬들과 실시간으로 연결되는 예능이 탄생합니다.

🏃
실시간 숨바꼭질
도심 속 숨바꼭질! 유튜버가 위치를 공유하면 팬들이 앱으로 추적. 먼저 찾은 팬에게 특별한 리워드를 제공합니다.
# 실시간 인터랙션
🗺️
성지순례 지도 제작
내가 자주 가는 장소를 셀럽 히어에 등록해 팬들만의 성지순례 루트를 만들어 드립니다. 팬심을 콘텐츠로!
# 팬과 함께
📡
야외 방송 팬미팅
방송 시작과 동시에 위치를 공유하면 근처 팬들이 실시간으로 모입니다. 기획 없이 자연스러운 팬미팅 완성.
# 즉흥 이벤트
🎯
팬 서프라이즈
특정 장소에서 기다리는 팬들을 앱으로 확인하고 깜짝 등장. 팬과 셀럽 모두가 주인공이 되는 순간.
# 서프라이즈
🏆
리얼 팬 챌린지
셀럽이 미션을 공개하고 앱으로 찾아온 팬들과 현장 미션 수행. 참여 영상을 업로드하면 구독자 폭발 보장.
# 바이럴 콘텐츠
🌟
셀럽 On-Air 이벤트
셀럽 히어 프리미엄 기능으로 실시간 방송 위치를 전달. 진짜 팬들이 현장으로 모이는 라이브 이벤트.
# 프리미엄 기능
Partner Program
